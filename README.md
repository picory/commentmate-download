# CommentMate 다운로드

소셜 미디어 댓글/DM 자동화 및 블로그 댓글 품앗이 통합 플랫폼

## 다운로드

| 플랫폼 | 다운로드 | 설명 |
|--------|---------|------|
| macOS (Apple Silicon) | [CommentMate-mac.dmg](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-mac.dmg) | M1/M2/M3/M4 Mac |
| macOS (Intel) | [CommentMate-mac-intel.dmg](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-mac-intel.dmg) | Intel Mac |
| Windows | [CommentMate-windows.msi](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-windows.msi) | Windows 10/11 |
| Linux | [CommentMate-linux.AppImage](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-linux.AppImage) | Ubuntu 등 |
| Chrome 확장 | [CommentMate-chrome.zip](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-chrome.zip) | 압축 해제 후 `chrome://extensions`에서 로드 |
| Android | [CommentMate-android.apk](https://github.com/picory/commentmate-download/releases/latest/download/CommentMate-android.apk) | Android 8.0+ |

## 설치 방법

### 데스크탑 앱
- **macOS**: `.dmg` 파일 열기 → Applications 폴더로 드래그
- **Windows**: `.msi` 파일 실행 → 설치 마법사 진행
- **Linux**: `.AppImage` 파일에 실행 권한 부여 후 실행

### Chrome 확장
1. `CommentMate-chrome.zip` 다운로드 및 압축 해제
2. Chrome에서 `chrome://extensions` 열기
3. "개발자 모드" 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 클릭
5. 압축 해제한 폴더 선택

### Android 앱
1. `CommentMate-android.apk` 다운로드
2. 설정 → 보안 → "출처를 알 수 없는 앱" 허용
3. APK 파일 설치
